## Capture status — 2026-05-28: live capture ATTEMPTED, BLOCKED

A genuine live-capture attempt was made in the documentation container:

- ✅ `cd frontend && npm install` — succeeded.
- ✅ `npm run dev` — Vite dev server came up and served the SPA
  (`HTTP 200`, `<title>Blokus RL</title>`) on **`http://localhost:3000/`**
  (note: port 3000 per the Vite config, not 5173).
- ✅ `npm i -D playwright` — installed (then reverted, not committed).
- ❌ `npx playwright install chromium` — **blocked**: the container network
  allowlist returned `403 'Host not in allowlist'` for
  `https://cdn.playwright.dev/...`. No system Chromium/Chrome/Firefox binary is
  present either.

**Conclusion:** no headless browser is available and the binary cannot be
downloaded here, so screenshots were not produced. The capture script written
for the attempt (`/tmp/capture.mjs`, Playwright; routes `/`, `/story`,
`/benchmark`, `/mcts-analysis` at 1440×900, full-page) is the basis for the
committed procedure in the [Visual Regression Plan](VISUAL_REGRESSION_PLAN.md).
Additional caveats observed: research routes (`/benchmark`, `/history`,
`/analysis`) require the FastAPI backend + MongoDB and arena/game data; the Play
board needs Pyodide WASM from a CDN at runtime (also subject to the allowlist).

Re-run the procedure in an environment with a browser and CDN access to populate
the table below and the `screenshots/` directory.
